## 💻 Getting Started

### Prerequisites

- Node.js >= 18.x
- npm or yarn or pnpm

### Installation

```bash
git clone https://github.com/<your-username>/metaquestsolutions.git
cd metaquestsolutions
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Admin Command Center

Access the private admin portal at `/admin` to manage:
- Workshop catalog and details
- Dedicated Google Form registration URLs for each cohort
- Live site announcements and hero copy
- Dynamic attendee records
